## Разбор топ-3

### Топ-1. polyakov-claude-skills — единственная живая упаковка Яндекса под Claude Code

**Что это.** Маркетплейс Claude Code `polyakov-claude-skills` из 22 плагинов на русском языке ([marketplace.json](https://github.com/artwist-polyakov/polyakov-claude-skills/blob/main/.claude-plugin/marketplace.json)). Пять плагинов — Яндекс: `yandex-direct`, `yandex-wordstat`, `yandex-metrika`, `yandex-search-api`, `yandex-webmaster`. Рядом — `sourcecraft-publisher` («Публикация статических артефактов на SourceCraft Sites (Yandex, работает в России)»), `telegram-channel-parser`, `crawl4ai-seo`, `docx-contracts`, `perplexity-search`, `reddit-skill`, `x-research`. Лицензия MIT ([README](https://github.com/artwist-polyakov/polyakov-claude-skills/blob/main/README.md)). 474 коммита с 2025-11-07, 224 за 90 дней; топ авторов — «master» (187), Aleksandr Poliakov (180), Vadim Ponomarev (81) ([commits](https://github.com/artwist-polyakov/polyakov-claude-skills/commits/main)). По плагинам: direct — 35 коммитов, последний 2026-09-23; wordstat — 26, 2026-10-08; metrika — 15, 2026-09-10; search-api — 19, 2026-09-21 (подсчёт по git-истории каталогов). В Anthropic community-маркетплейсе пакета нет (проверено по [каталогу](https://github.com/anthropics/claude-plugins-community/blob/main/.claude-plugin/marketplace.json)).

**Что закрывает в цикле.**
- **Данные спроса.** `yandex-wordstat` работает «через Wordstat API в Yandex Cloud Search API v2»; авторизация — IAM по JSON-ключу сервисного аккаунта или API-ключ. Умеет топ до 2000 запросов, ассоциации, динамику, регионы, экспорт CSV и поиск «упущенного спроса» по XLSX-выгрузке Директа. Правило скилла — «VERIFY INTENT via web search»: интент запроса проверяется веб-поиском до пометки «целевой». В `dynamics` при недельном и месячном периоде работает только оператор `+` ([SKILL.md](https://github.com/artwist-polyakov/polyakov-claude-skills/blob/main/plugins/yandex-wordstat/skills/yandex-wordstat/SKILL.md)).
- **Скаут и разведка конкурентов.** `yandex-search-api` отдаёт «инфоконтексты» — выдержку страницы примерно на 500 токенов. Ограничения: только синхронный режим, только `SEARCH_TYPE_RU`, не больше 20 документов. Цена по тексту скилла — 1 500 ₽ за 1000 запросов против 488 ₽ у обычного синхронного (официальный прайс здесь не проверялся) ([SKILL.md](https://github.com/artwist-polyakov/polyakov-claude-skills/blob/main/plugins/yandex-search-api/skills/yandex-search-api/SKILL.md)).
- **Метрика.** Токен `YANDEX_METRIKA_TOKEN` лежит в `config/.env`; для чтения нужен `metrika:read`, для сегментов и доступов — `metrika:write`. Отчёты без сэмплирования (accuracy=1), с фильтром роботов; cache-first, вывод в stdout ограничен 30 строками ([SKILL.md](https://github.com/artwist-polyakov/polyakov-claude-skills/blob/main/plugins/yandex-metrika/skills/yandex-metrika/SKILL.md)).
- **Smoke-тест в Директе.** Скрипты на Python 3.11 «сторонних библиотек нет», запуск `uv run scripts/…`. Пишущая команда без флага показывает план «было → станет»; `--apply` выполняет правку и перечитывает объект. Но: «Если пользователь уже поручил конкретное действие, повторное подтверждение не требуется» ([SKILL.md](https://github.com/artwist-polyakov/polyakov-claude-skills/blob/main/plugins/yandex-direct/skills/yandex-direct/SKILL.md)). Правки пишутся в журнал `audit-log.jsonl` ([writer.py](https://github.com/artwist-polyakov/polyakov-claude-skills/blob/main/plugins/yandex-direct/skills/yandex-direct/scripts/lib/writer.py)). Справочник бюджетов требует: «При каждом новом запуске предлагай проверить недельный лимит всего кабинета». Команда лимита использует `AccountManagement` версии Live 4, автор проверил её 11.09.2026 в рублёвом тестовом кабинете ([BUDGETS.md](https://github.com/artwist-polyakov/polyakov-claude-skills/blob/main/plugins/yandex-direct/skills/yandex-direct/references/BUDGETS.md)).
- **Прогноза бюджета нет.** Методы `CreateNewForecast`, `GetForecast`, `GetForecastList`, `DeleteForecastReport` перечислены только в карте API ([API_MAP.md](https://github.com/artwist-polyakov/polyakov-claude-skills/blob/main/plugins/yandex-direct/skills/yandex-direct/references/API_MAP.md)); скриптов с `CreateNewForecast` нет (поиск по репозиторию). Рабочий прогноз Live 4 — в yamcp (предыдущий отчёт, слой 4).

**Как подключить (не выполнялось).** `/plugin marketplace add artwist-polyakov/polyakov-claude-skills`, затем `/plugin install yandex-wordstat` и т. д. ([README](https://github.com/artwist-polyakov/polyakov-claude-skills/blob/main/README.md)). Для стороннего маркетплейса автообновление по умолчанию выключено ([install docs](https://code.claude.com/docs/en/plugins/install.md)).

**Риски.** Сторонний маркетплейс, Anthropic его не проверяет ([anthropic-marketplaces](https://code.claude.com/docs/en/plugins/anthropic-marketplaces.md)). В репозитории около 330 файлов `.sh`/`.py`/`.js` (с тестами) — исполняемый код, который Claude запускает через Bash; хуков, `.mcp.json` и `bin/` нет (подсчёт по дереву git). Токены лежат в `config/.env` внутри каталога скилла; запрет «не открывай и не выводи токен в диалог» — инструкция модели, а не защита. Фраза о необязательном повторном подтверждении противоречит гейту совета на траты. Кто стоит за автором коммитов «master» — не проверено.

**Что сделать** (предложение). Форкнуть и закрепить SHA в своём `marketplace.json` (поле `sha` — [marketplace-reference](https://code.claude.com/docs/en/plugins/marketplace-reference.md)). Агентам выдать только токен Директа без права записи. Дополнительно — deny-правило на `--apply`: «Deny rules block in every mode, including `bypassPermissions`» ([permission-modes](https://code.claude.com/docs/en/permission-modes.md)). Но шаблонный deny на Bash обходится, поэтому реальный барьер — отсутствие пишущего токена в среде агента. Прогноз Live 4 дописать по образцу yamcp. Ключи Search API и Wordstat — от отдельного сервисного аккаунта с квотами.

**Вердикт: брать** wordstat, search-api и metrika с закреплённой версией; direct — только для чтения и плана правок; sourcecraft-publisher — кандидат на хостинг лендинга (работа SourceCraft Sites из РФ — по описанию плагина, не проверено).

### Gaps

- Дата и состав «расширенной» версии small-business (31 vs 44 скилла в разных источниках) — по сниппету поиска противоречивы; в репозитории сейчас 44.

## Вопрос 4. Paperclip + Claude Code: как сочетаются

### Takeaway
Paperclip запускает Claude Code как «сотрудника» через адаптер `claude_local` и подкладывает ему скиллы компании на время запуска. Скиллы хранятся в библиотеке компании с закреплением на SHA и уровнем доверия. Поэтому готовые пакеты (polyakov, marketingskills, свои) раскладываются по ролям Paperclip. Но адаптер по умолчанию пропускает подтверждения разрешений, так что денежные действия нужно запирать вне скиллов.

### Cited Findings
- «The `claude_local` adapter runs Anthropic's Claude Code CLI locally. It supports session persistence, skills injection, and structured output parsing». Поля: `cwd`, `model` (по умолчанию `claude-opus-5`), `promptTemplate`, `env`, `timeoutSec`, `maxTurnsPerRun` (по умолчанию 300), `dangerouslySkipPermissions` («default: `true`; required for headless runs where interactive approval is impossible») ([claude-local.md](https://github.com/paperclipai/paperclip/blob/master/docs/adapters/claude-local.md)).
- «Skills Injection: The adapter creates a temporary directory with symlinks to Paperclip skills and passes it via `--add-dir`». Команда `npx paperclipai agent local-cli claudecoder --company-id <id>` «installs Paperclip skills in `~/.claude/skills`» (там же).
- Авторизация — `ANTHROPIC_API_KEY`, `CLAUDE_CODE_OAUTH_TOKEN` или подписка Claude Code; сессии Claude Code продолжаются между heartbeat-запусками (там же).
- В плане синхронизации скиллов: `claude_local` и `codex_local` — «implemented, `ephemeral`»; в матрице адаптеров также gemini_local, grok_local, acpx_local, opencode_local, pi_local, cursor, openclaw_gateway (их статус синхронизации скиллов не читался) ([план 2026-03-14](https://github.com/paperclipai/paperclip/blob/master/doc/plans/2026-03-14-adapter-skill-sync-rollout.md)).
- Skills Store: каталог `@paperclipai/skills-catalog` плюс библиотека компании (`company_skills`). У скиллов есть метаданные `recommendedForRoles` и `trustLevel` (`markdown_only` / `assets` / `scripts_executables`, «derived from the files, not self-declared»). Импорт из GitHub, skills.sh, URL; «Git-backed sources must resolve to a pinned 40-character commit SHA»; «Importing never executes scripts, hooks, dependency installers, or builds» ([skills-store.md](https://github.com/paperclipai/paperclip/blob/master/docs/guides/agent-developer/skills-store.md)).
- npm `paperclipai` 2026.1005.0, изменён 2026-10-09 ([npm](https://registry.npmjs.org/paperclipai)); MIT, 99.1k★ и вердикт «брать пилотом» — в предыдущем отчёте (слой 1).
- В community-каталоге есть плагин githubclip: «routes work by issue labels into persona-based agents (Orchestrator, CEO, and workers)» ([каталог](https://github.com/anthropics/claude-plugins-community/blob/main/.claude-plugin/marketplace.json)) — облегчённый аналог без совета и бюджетов.

### Inferences
Схема (предложение):
1. Роли директора, аналитика, маркетолога, скаута — агенты Paperclip на `claude_local`, каждый со своим `cwd`.
2. Скиллы импортируются в библиотеку компании из форков с закреплённым SHA и раздаются по ролям. Аналитику — polyakov wordstat и search-api, свой стоп-фильтр по RFSD, свой калькулятор max CPC. Маркетологу — marketingskills (выборочно), ru-text, yandex-direct в режиме плана. Директору — свои скиллы турнира и отчёта совету с протоколом в стиле board-meeting.
3. Скиллы со скриптами получат уровень `scripts_executables` — их нужно читать целиком.
4. Так как `dangerouslySkipPermissions=true`, единственные надёжные гейты — deny-правила (действуют даже в bypass) и отсутствие пишущих токенов у агентов. Траты идут только через шлюз в бэкенде после одобрения совета в Paperclip.
5. Поле `allowed-tools` у скиллов не зависит от доверия к рабочей папке. Это ещё один довод не класть сторонние скиллы в проектный `.claude/skills` без ревью (см. раздел безопасности).

### Gaps
- Ничего не запускалось. Не проверено, поддерживает ли `recommendedForRoles` произвольные роли («marketer», «analyst») и как ведут себя скиллы со скриптами при `--add-dir`.
- `claude_local` требует доступа к Anthropic, который из РФ официально не предоставляется. Переносимость тех же скиллов на `opencode_local` с OpenAI-совместимым endpoint — гипотеза из предыдущего отчёта, в бою не проверена.

## Безопасность цепочки поставок скиллов и плагинов

### Takeaway
Плагин Claude Code — это исполняемый код с правами пользователя, а скилл — инструкции, которые меняют поведение агента. В 2026 году отравление реестров скиллов стало массовым (ClawHub — сотни вредоносных скиллов, часть нацелена на пользователей Claude Code), а Claude Code получил несколько уязвимостей через проектные файлы. Официальный маркетплейс Anthropic по найденным данным не компрометировался. Защита — закрепление SHA, чтение хуков, `.mcp.json` и `bin/`, свой маркетплейс-зеркало и managed-настройки.

### Cited Findings
- **Что может плагин.** «A Claude Code plugin you install can execute arbitrary code on your machine with your user privileges». Хуки, мониторы, MCP- и LSP-серверы и процессы модов работают вне песочницы; `bin/` плагина добавляется в PATH Bash; скиллы, команды и агенты «enter Claude's context as instructions» ([security](https://code.claude.com/docs/en/plugins/security.md)).
- **Уровни маркетплейсов.** Имена официального и community-уровней принимаются только из `github.com/anthropics/`. Community-каталог «pins a plugin to a commit SHA, which it does for nearly every entry», и другой коммит Claude Code поставить откажется. Источник `archive` можно закрепить `sha256` ([security](https://code.claude.com/docs/en/plugins/security.md)). В текущем community-каталоге закреплено 2 274 из 2 284 записей ([marketplace.json](https://github.com/anthropics/claude-plugins-community/blob/main/.claude-plugin/marketplace.json)).
- **Автообновление.** Включено по умолчанию для `claude-plugins-official` и официальных имён, кроме `knowledge-work-plugins` и `first-party-plugins`; выключено для community, сторонних и локальных маркетплейсов ([install](https://code.claude.com/docs/en/plugins/install.md)). При автообновлении «the files you reviewed can change on disk» ([security](https://code.claude.com/docs/en/plugins/security.md)).
- **Ревью перед установкой** (по документации):
  - `claude plugin marketplace list` — откуда добавлен маркетплейс;
  - панель `/plugin` с разделом «Will install»;
  - чтение `hooks/hooks.json`, `.mcp.json` и всего `bin/`;
  - `claude --plugin-dir <dir> plugin details <name>` — «Component inventory» без запуска сессии ([security](https://code.claude.com/docs/en/plugins/security.md)).
- **Закрепление версии в своём маркетплейсе.** Поле `sha` — «a full 40-character lowercase commit SHA», при заданных `ref` и `sha` выбирается `sha` ([marketplace-reference](https://code.claude.com/docs/en/plugins/marketplace-reference.md)).
- **Managed-настройки:** `strictKnownMarketplaces` (allowlist; `[]` блокирует всё, включая официальный), `blockedMarketplaces`, `allowManagedHooksOnly`, `strictPluginOnlyCustomization`, `disableCommandPluginSources`, `pluginTrustMessage`, `syncClaudeAiPlugins` ([org](https://code.claude.com/docs/en/plugins/org.md)).
- **Скиллы и доверие к папке.** «Workspace trust doesn't gate this field. Claude Code applies a project skill's `allowed-tools` even in a `-p` run in a folder you've never trusted. A skill can grant itself broad tool access» ([skills](https://code.claude.com/docs/en/skills.md)). При этом «Deny rules block in every mode, including `bypassPermissions`» ([permission-modes](https://code.claude.com/docs/en/permission-modes.md)).
- **ClawHavoc / ClawHub (OpenClaw)** (по сниппету поиска). Koi Security в начале февраля 2026 года нашла 341 вредоносный скилл из 2 857, позже — 824; полезная нагрузка — стилер AMOS. С 27 по 29 января опубликовано 28 вредоносных скиллов, нацеленных на пользователей Claude Code и Moltbot. IBM X-Force — более 1 100 загрузок; Unit 42 (23.06.2026) — скиллы, проходящие сканер ClawHub за счёт раздувания файлов ([eSecurity Planet](https://esecurityplanet.com/threats/hundreds-of-malicious-skills-found-in-openclaws-clawhub), [Antiy](https://www.antiy.net/p/clawhavoc-analysis-of-large-scale-poisoning-campaign-targeting-the-openclaw-skill-market-for-ai-agents/), [Termdock](https://termdock.com/en/blog/clawhub-malicious-skills-incident), [Aviatrix](https://aviatrix.ai/threat-research-center/openclaw-2026-clawhub-malicious-skills/)). Цифры в источниках расходятся: 341, 386, 824, 1 184, «1 100+».

- **Уязвимости Claude Code через проектные файлы.** GHSA-ph6w-f82w-28w6: «Arbitrary Code Execution Due to Insufficient Startup Warning», High, CVSS 4.0 — 8.7, версии < 1.0.87, опубликовано 2025-09-02 ([GHSA](https://github.com/anthropics/claude-code/security/advisories/GHSA-ph6w-f82w-28w6)). - **Уязвимость в установщике.** davila7/claude-code-templates — command injection в Console Bridge (GHSA-4jm9-m3fr-9jpx), исправлено в 1.29.7 2026-10-09 ([commits](https://github.com/davila7/claude-code-templates/commits/main)).
- Подтверждённой компрометации официального маркетплейса Anthropic поиск не нашёл (по сниппету поиска).
- Paperclip при импорте не исполняет скрипты и требует 40-символьный SHA ([skills-store.md](https://github.com/paperclipai/paperclip/blob/master/docs/guides/agent-developer/skills-store.md)).

### Inferences
Чек-лист проверки скилла или плагина (предложение):
1. Брать только из форка в своём GitHub с закреплённым SHA. Свой маркетплейс-зеркало, автообновление выключено.
2. В managed-настройках — `strictKnownMarketplaces` только на свой маркетплейс, `allowManagedHooksOnly`.
3. Перед закреплением читать SKILL.md целиком (инъекции прячут в середине файла — по сниппету поиска), а также `allowed-tools`, `hooks.json`, `.mcp.json`, `bin/` и все скрипты; запустить `plugin details`.
4. Сторонние скиллы не класть в проектный `.claude/skills`: их `allowed-tools` действует без доверия к папке.
5. Ключи с правом записи и трат никогда не держать в `config/.env` скилла или env агента.
6. Для пакетов с сотнями коммитов в месяц (marketingskills, ruflo) ревью при каждом обновлении — главная статья затрат. Поэтому брать выборочно и обновлять по расписанию, а не автоматически.

### Gaps
- Первоисточники Snyk, PromptArmor, Check Point, OSV, Koi не открывались (DNS); цифры — по сниппету поиска и противоречат друг другу.
- Нет данных о вредоносных пакетах в community-маркетплейсе Anthropic или в репозиториях-кандидатах. Целевой аудит кода кандидатов (кроме чтения выборочных файлов) не проводился.

## Вывод: что взять готовым / что как референс / что писать самому

**Взять готовым** (форк + закреплённый SHA + свой маркетплейс; предложение):
- polyakov-claude-skills: `yandex-wordstat`, `yandex-search-api`, `yandex-metrika` — как есть; `yandex-direct` — только чтение и план правок; `sourcecraft-publisher` — после проверки работы из РФ.
- ru-text — контроль русских текстов маркетолога.
- anthropics/skills: `skill-creator` (писать и тестировать свои скиллы), `mcp-builder` (свои MCP для RFSD, Checko, Live 4); `xlsx`/`pptx`/`docx` — для пакетов совета, по условиям Anthropic, без форка.
- knowledge-work-plugins (форк Markdown, без коннекторов): product-management, marketing, data.
- marketingskills выборочно: offers, pricing, copywriting, ad-creative, cro, ab-testing, launch, customer-research.
- Paperclip `claude_local` + Skills Store — оболочка ролей и совета, пилотом (как в предыдущем отчёте), с deny-правилами и без пишущих токенов у агентов.

**Как референс:**
- small-business (гейт «деньги и клиенты — только после явного да», роутер);
- wshobson startup-business-analyst (метрики LTV:CAC по валовой марже, market sizing);
- alirezarezvani board-meeting и cfo-advisor (протокол совета);
- gstack `/office-hours` и `/plan-ceo-review` (вопросы директора о спросе);
- BMAD: Mary, brainstorming, PRFAQ, party-mode;
- agency-agents: paid-media, FP&A, NEXUS;
- stufently/yandex-mcp (упаковка «MCP + скилл»);
- haytham (фазовые гейты GO/NO-GO/PIVOT со спецификацией OpenSpec);
- debate- и council-плагины (agent-sh/debate, decision-council) — как формат обсуждения, не как турнир;
- theYahia/WWmcp (MCP для amoCRM, Битрикс24, 1С, ЮKassa — позже, после первых продаж);
- кейс Anthropic Growth Marketing (скиллы бренда + команда + CSV + ручная проверка).

**Не брать:** ruflo (claude-flow), contains-studio (нет лицензии), ccpm (заброшен и про разработку), SuperClaude (затухает, разработка), financial-services (IB и PE). hesreallyhim/awesome-claude-code и davila7 CLI использовать только как каталоги для поиска, без установки.

**Писать самому** (готового в упаковке Claude Code не найдено):
1. Стоп-фильтр с «монополистом»: скилл + MCP поверх RFSD и Checko.
2. Прогноз бюджета Директа через Live 4: скилл или MCP по образцу yamcp.
3. Калькулятор max CPC по исправленной формуле предыдущего отчёта; в основе — startup-metrics-framework.
4. Swiss-турнир финалистов с перестановкой пар и судьёй другого семейства.
5. Лестница smoke-теста с гейтами совета и шлюзом трат (Директ, ЮKassa) в бэкенде.
6. Скилл предоплаты ЮKassa поверх официального MCP только для чтения.
7. Юридические чек-листы 152-ФЗ и 38-ФЗ.
8. Субагенты-роли (директор, аналитик, маркетолог, скаут) с ограниченными инструментами.
9. Свой маркетплейс-зеркало с закреплёнными SHA и managed-настройками.
