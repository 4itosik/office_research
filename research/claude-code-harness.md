### c1-выводы (черновые абзацы)

Хорошо ложатся: роли (субагенты с минимальными правами), директор (агент главной сессии), SOP (skills с ручным запуском и скриптами), недельный фан-аут и турнир (воркфлоу со схемами), устав (CLAUDE.md + managed settings), упаковка (плагин), регрессия (plugin eval), аудит как источник событий. Для основателя это продолжение привычной среды.

Не ложатся (раздел 3 c1): деньги; состояние цикла; реестр решений совета и UI одобрений; надёжный планировщик; коннекторы РФ (MCP — только протокол); детерминированная математика — в скриптах; лендинг, хостинг, платёжный сервис; аудит, защищённый от подмены; независимость от провайдера (только Claude); юридический гейт; калибровка судей.

Темп: 241 релиз с 1 января по 8 октября 2026, 20–28 в месяц ([changelog](https://code.claude.com/docs/en/changelog)); умолчания менялись: вложенность субагентов 5 → выкл. → 3 ([changelog v2.1.219](https://code.claude.com/docs/en/changelog#2-1-219)); auto mode по умолчанию с v2.1.283 ([permission-modes](https://code.claude.com/docs/en/permission-modes#which-mode-a-session-starts-in)). Управление версией: `autoUpdatesChannel: "stable"`, `minimumVersion`, `DISABLE_AUTOUPDATER` ([settings-reference](https://code.claude.com/docs/en/settings-reference#autoupdateschannel)).

Хуки fail-open: exit 1 — неблокирующая ошибка; «a mistyped path in `settings.json` leaves the gate silently disabled»; таймаут PreToolUse не блокирует: «don't count on a stalled hook to act as a gate» ([hooks](https://code.claude.com/docs/en/hooks#exit-code-output), [timeouts](https://code.claude.com/docs/en/hooks#timeouts)); HTTP не-2xx — неблокирующая ([http](https://code.claude.com/docs/en/hooks#http-response-handling)). v2.1.295: `onFailure: "block"` ([changelog](https://code.claude.com/docs/en/changelog#2-1-295)); в справочнике нет. SDK колбэк-хук по таймауту блокирует ([agent-sdk/hooks](https://code.claude.com/docs/en/agent-sdk/hooks#hook-timeout)). `if` — best-effort ([hooks](https://code.claude.com/docs/en/hooks#common-fields)). Mod `tool.check` может одобрить вызов поверх deny вне managed settings ([permissions](https://code.claude.com/docs/en/permissions#extend-permissions-with-hooks)). Issues (по листингу GitHub): #92074 VS Code, #95833 Desktop, #88738 silently stops, #89251 Bash обходит Write|Edit, #95726 ask → deny в headless.

requiresUserInteraction: запрос на каждый вызов даже в acceptEdits/auto/bypass; allow-правила не снимают; хук не может снять ([hooks](https://code.claude.com/docs/en/hooks#pretooluse-decision-control)); `dontAsk` отклоняет; `--permission-prompt-tool` allow → deny; `canUseTool` получает и может одобрить; на Remote Control одного касания нет ([mcp](https://code.claude.com/docs/en/mcp#require-approval-for-a-specific-tool)).

SDK: порядок хуки → deny → ask → режим → allow → canUseTool; ask и requiresUserInteraction всегда доходят до колбэка ([agent-sdk/permissions](https://code.claude.com/docs/en/agent-sdk/permissions#how-permissions-are-evaluated)). «Unless previously approved, Anthropic does not allow third party developers to offer claude.ai login or rate limits for their products, including agents built on the Claude Agent SDK» ([agent-sdk/overview](https://code.claude.com/docs/en/agent-sdk/overview)); OAuth — для «ordinary use of Claude Code» ([legal-and-compliance](https://code.claude.com/docs/en/legal-and-compliance)).

Headless шаблон: `claude --bare -p "<стадия>" --agents ./company/agents.json --mcp-config ./company/mcp.read.json --strict-mcp-config --settings ./company/settings.json --permission-mode dontAsk --json-schema "$(cat schema.json)" --max-turns 40 --max-budget-usd 3 --output-format json`. `--bare` «will become the default for `-p` in a future release» ([headless](https://code.claude.com/docs/en/headless#start-faster-with-bare-mode)). `--permission-prompts none` (v2.1.259+) ([headless](https://code.claude.com/docs/en/headless#turn-off-permission-prompts-in-unattended-runs)).

Workflows W1/W2/W3: `/weekly-scout` → гейт → `/weekly-data` → `/weekly-tournament` → гейт GO; оценка 100–250 агентов в неделю (допущение), лимит 1000; «Large workflow» > 25 агентов или > 1,5 млн токенов ([workflows](https://code.claude.com/docs/en/workflows#cost)). На лимите пауза только в интерактивной сессии с подпиской ([workflows](https://code.claude.com/docs/en/workflows#when-a-run-hits-your-usage-limit)).
